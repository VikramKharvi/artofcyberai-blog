01

The objective

Learn one conditional distribution at every position.

Given a token sequence x₁ … xₜ, an autoregressive model assigns a probability to the sequence by factorizing it into next-token conditionals. Training minimizes the negative log-probability of the observed next token at every valid position.

Autoregressive factorizationp(x₁:T) = ∏ₜ pθ(xₜ | x<t)

The same parameters solve every position. Each prefix becomes a training example.

Token-average lossLpre = − (1 / N) Σₜ log pθ(xₜ | x<t)

N counts non-padding target tokens across the global batch.

For an input tensor X with shape [B,T], the targets are the same stream shifted by one position. The model returns logits [B,T,V], where V is vocabulary size. Cross-entropy compares every logit vector against one target ID. This simple interface should remain visible throughout the implementation; most silent failures are violations of shapes, masks, shifts, or token counts around it.

# one contiguous token stream, sampled at offset s
x = tokens[s : s + B*T].view(B, T)
y = tokens[s + 1 : s + B*T + 1].view(B, T)
logits = model(x)                 # [B, T, V]
loss = cross_entropy(logits.view(-1, V), y.view(-1))
02

The tokenizer

Tokenization is the model’s first architecture decision.

Text arrives as Unicode. A practical tokenizer first maps it to a byte representation so any string can be encoded, then learns reusable byte sequences. Byte-pair encoding begins with 256 byte values, counts adjacent pairs in the training sample, merges the most useful pair, and repeats until it reaches the requested vocabulary size.

vocab = all_256_bytes
while len(vocab) < target_size:
    pair = most_frequent_adjacent_pair(corpus_ids)
    new_id = len(vocab)
    merge_table[pair] = new_id
    corpus_ids = replace_pair(corpus_ids, pair, new_id)

The learned artifact is not only a vocabulary. It is an ordered merge table, text-splitting policy, byte mapping, normalization policy, and special-token table. Encoding applies merges according to that fixed order. Decoding expands token IDs to bytes and decodes the resulting byte stream. Two non-negotiable tests are decode(encode(text)) == text and deterministic IDs across machines.

Measure fertility—the average tokens per character, word, or byte—by language and domain. A tokenizer that looks efficient on English prose may expand source code, numbers, or another script enough to change the effective context window and training mixture.

03

The corpus

Build a data pipeline whose decisions can be audited.

The pre-training corpus determines which patterns receive gradient updates. A production pipeline normally moves through source registration, parsing, language and quality signals, exact and approximate deduplication, policy filtering, benchmark decontamination, mixture weighting, tokenization, and immutable sharding.

sources→parse→filter→dedupe→mix→tokenize→shard

Keep document boundaries explicit. Concatenating documents without an end marker teaches false transitions between unrelated texts. Packing several documents into one context improves utilization, but the token stream must retain boundary tokens and the training manifest must retain source membership.

Split evaluation documents before approximate deduplication, then remove overlapping clusters from training. Otherwise a benchmark can look strong because the model saw a paraphrase, duplicate, or answer-bearing neighbor. Report mixture weights in tokens—not only documents or bytes—because tokens are what produce optimizer updates.

04

The tensors

Make the dimensional contract explicit.

A decoder-only transformer starts with token IDs [B,T]. Token embeddings produce [B,T,C]; positional information is added or applied inside attention; a stack of blocks preserves [B,T,C]; the language-model head projects to [B,T,V].

TensorShape
token_ids

B × T

hidden

B × T × C

q, k, v

B × H × T × D; D = C/H

attention_scores

B × H × T × T

logits

B × T × V

The 124M-class GPT-2 configuration is a useful reference point: 12 blocks, width 768, 12 attention heads, context 1024, and vocabulary 50,257. The token embedding and output projection can share weights. The majority of each block’s parameters live in the attention projections and the expansion/contraction matrices of the feed-forward path.

Parameter counts should be calculated from the configuration and asserted at startup. A mismatched bias, untied output matrix, or incorrect feed-forward width can add millions of parameters while leaving the code visually plausible.

05

Attention

Causal attention is content-addressed communication.

For hidden states X ∈ ℝT×C, learned projections create queries, keys, and values. Query-key dot products measure which previous positions matter to each current position. The scores are scaled, future positions are masked, a softmax produces weights, and the weights mix value vectors.

Scaled causal self-attentionA = softmax((QKᵀ / √D) + M)

Mij = −∞ when j > i; otherwise it is zero.

Context updateY = A V

Each row of Y is a learned weighted combination of permitted positions.

q, k, v = project(x).chunk(3, dim=-1)
q, k, v = split_heads(q), split_heads(k), split_heads(v)
scores = (q @ k.transpose(-2, -1)) / sqrt(head_dim)
scores = scores.masked_fill(causal_mask == 0, -inf)
weights = softmax(scores, dim=-1)
y = merge_heads(weights @ v)

With dense attention, the score matrix grows as T². Longer context therefore increases both memory and computation sharply. Fused attention kernels avoid writing the full score matrix to high-bandwidth memory, which changes feasibility without changing the mathematical result.

06

The block

Alternate communication with per-token computation.

A modern pre-normalized decoder block contains two residual updates. Attention moves information across positions. A feed-forward network transforms each position independently, usually expanding the channel dimension before projecting it back.

x = x + attention(layer_norm_1(x))
x = x + mlp(layer_norm_2(x))

mlp(h) = W2 * GELU(W1 * h)

Residual paths preserve an identity route through depth. Pre-normalization helps gradients reach earlier layers. Initialization must account for the accumulation of residual branches; scaling selected output projections by depth keeps the initial residual stream from growing too quickly.

The model ends with a final normalization and a vocabulary projection. Generation uses the logits at the last position, applies a sampling policy, appends the selected token, and repeats. This loop is useful for qualitative checks during training, but samples should never replace held-out loss and fixed evaluations.

07

The run

Define optimization in tokens, not device-local batches.

AdamW maintains first and second moments for every parameter and applies decoupled weight decay to selected matrices. A typical schedule warms the learning rate from zero, holds or peaks, then decays. Gradient clipping limits rare spikes. Mixed numerical formats reduce memory traffic, while sensitive reductions and optimizer state remain at safer precision.

Global tokens per optimizer updateG = world_size × micro_batch × sequence_length × accumulation_steps

Every learning-rate and throughput comparison should state G.

optimizer.zero_grad(set_to_none=True)
for micro_step in range(accumulation_steps):
    x, y = next_batch()
    with autocast(dtype=bf16):
        loss = model(x, y) / accumulation_steps
    loss.backward()
clip_grad_norm_(model.parameters(), max_norm)
optimizer.step()
scheduler.step()

Distributed data parallelism places a model replica on each accelerator and averages gradients. Tensor or pipeline partitioning becomes necessary when one replica no longer fits. The data loader must assign non-overlapping token ranges per worker, and checkpoints must capture model, optimizer, scheduler, random state, data cursor, and global token count.

08

The evidence

A base model is complete only when the run is explainable.

Before scaling, overfit one tiny batch, verify the expected loss decrease, compare attention against a slow reference, round-trip tokenizer tests, resume from a checkpoint, and confirm that one-device and multi-device updates agree within tolerance. Then run a short fixed-token experiment that produces a known loss curve and throughput envelope.

During the full run, save immutable manifests and periodic checkpoints. Evaluate on held-out domains, inspect loss by source and language, track exact training tokens, and maintain contamination checks. Record the code revision, configuration, dependency versions, hardware, numerical mode, and kernel choices.

Performance is part of intelligence.

A system that wastes half its accelerator time learns less under the same budget. Throughput, stability, and recoverability determine how many hypotheses can be tested and how much clean learning can be purchased. The pre-training artifact is therefore more than weights: it is the tokenizer, data manifest, model configuration, checkpoint state, and evidence that the run behaved as intended.
